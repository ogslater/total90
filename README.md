A página mostra perfils do discord sem uso de api. Tecnologias utilizadas

HTML: Estrutura da página
CSS: Estilização e layout
JavaScript: embed dos perfils; cursor para o  site;, anti-especionar elementos; api que muda as fotos automaticamente. 

Funcionalidades

mostra o perfil do discord e conexões

Como usar

Abra o arquivo index.html no vscode.
va em: <div class="all"> e ponha o nick e user, junto com as badges do perfil
